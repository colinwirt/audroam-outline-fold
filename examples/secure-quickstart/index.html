Secure quick start

Create a key from your own passphrase, seal one branch, lock, unlock. This page uses the same envelope and keyring as production: of-seal-v3 with an Argon2id-wrapped key. Nothing is saved; reload and it is gone. All demos

0 · The outline

Edit it if you like. The branch with <id:vault> is the one that gets sealed.

1 · Create a key

Pick a passphrase of 16 or more characters, or let your password manager suggest one. The key is random; your passphrase only wraps it (Argon2id, 64 MiB, about a second).

2 · Seal the branch

What a host saves (serialize / portableCopy): the public label, the ciphertext and the wrapped keyring. No passphrase, no plaintext.



The public view (cleanCopy): no ciphertext, no keyring.





3 · Lock


Drops every key from memory and reloads the outline from the saved text, as a host would after a reload.





4 · Unlock


The unlock card is always empty, so your browser or password manager can fill it.
