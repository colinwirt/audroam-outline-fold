# Outline fixtures

Paste any `.md` into the [React live](../../react-live/) textarea.

Copies of the example outlines plus a few extra boards. Files with a twin under `examples/<name>/` have the same outline rows (a test checks this).

These are public, plain outlines: no ciphertext, no keyring, no passwords, and every name and number is made up. Rows that hint at secrets (logins, codes, contacts) are plain titles here; in a real outline you seal them with your own key. See the [Secure quick start](../secure-quickstart/).

The 0.6.x copies with demo-crypto locked rows moved to `tests/fixtures/demo-sealed/` as DEV-ONLY test fixtures.
